# Use Supabase pgvector and Gemini embeddings

Streamwise AI will store Project Document chunks and embeddings in hosted Supabase Postgres with pgvector, and generate normalized 768-dimensional vectors through the raw Gemini `gemini-embedding-2` REST API. This introduces the product's first durable backend, preserves compatibility with a later pgvector index, and reuses the existing Gemini integration; changing the embedding model or dimensionality requires re-indexing every Project Document. Because `gemini-embedding-001` and `gemini-embedding-2` produce incompatible vector spaces, Streamwise will not maintain a mixed or duplicate fallback index. If Embedding 2 is temporarily unavailable, retrieval may degrade explicitly to PostgreSQL full-text search while preserving Source Reference and Insufficient Evidence requirements.
